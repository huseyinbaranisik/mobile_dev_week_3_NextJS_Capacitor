## 🇬🇧 English

> **Course:** Mobile App Development · Week 3 assignment

### 📝 About the Project
A hybrid app project that combines the powerful web architecture of **Next.js** with the mobile capabilities of **Capacitor**. From a single codebase it delivers both a high-performance web experience and native app builds for Android and iOS.

It was built as an example of a scalable hybrid app, using modern UI components and a real-time data layer.

### 🌟 Highlights
* ⚡ **Hybrid structure:** Capacitor integration brings the web project straight to mobile devices.
* 🛡️ **Strong backend:** Real-time data sync and secure authentication with Supabase.
* 🎨 **Smooth UI:** Accessible components with Tailwind CSS and Radix UI, animations with Framer Motion.
* 🛠️ **Solid architecture:** Type-safe (TypeScript) development on the Next.js 15 App Router.

### 🛠️ Tech Stack

| Component | Technology | Purpose |
| :--- | :--- | :--- |
| **Framework** | Next.js 15 | App architecture and SSR/static generation |
| **Platform** | Capacitor | Mobile adaptation (Android/iOS) |
| **Database** | Supabase | Real-time data & auth |
| **Style / UI** | Tailwind & Radix | Design system and accessibility |
| **Animation** | Framer Motion | Interactive UI |

## 🇹🇷 Türkçe

> **Ders:** Mobil Uygulama Geliştirme · 3. hafta ödevi

### 📝 Proje Hakkında
Bu çalışma, **Next.js**'in güçlü web mimarisini **Capacitor**'ın mobil yetenekleriyle birleştiren hibrit bir uygulama projesidir. Tek bir kod tabanı üzerinden hem yüksek performanslı web deneyimi hem de Android/iOS platformları için yerel (native) uygulama çıktıları sunar.

Proje, modern UI bileşenleri ve gerçek zamanlı veri yönetimi altyapısı kullanılarak, ölçeklenebilir bir hibrit uygulama örneği oluşturmak amacıyla geliştirilmiştir.

### 🌟 Öne Çıkan Özellikler
* ⚡ **Hibrit Yapı:** Capacitor entegrasyonu sayesinde web projesini doğrudan mobil cihazlara taşıma imkanı.
* 🛡️ **Güçlü Backend:** Supabase ile gerçek zamanlı veri senkronizasyonu ve güvenli kimlik doğrulama.
* 🎨 **Akıcı Arayüz:** Tailwind CSS ve Radix UI ile erişilebilir, Framer Motion ile animasyonlu kullanıcı deneyimi.
* 🛠️ **Gelişmiş Mimari:** Next.js 15 App Router mimarisi üzerinde yükselen, tip güvenli (TypeScript) geliştirme süreci.

### 🛠️ Teknoloji Yığını

| Bileşen | Teknoloji | Kullanım Amacı |
| :--- | :--- | :--- |
| **Framework** | Next.js 15 | Uygulama Mimarisi ve SSR/Static Üretim |
| **Platform** | Capacitor | Mobil Adaptasyon (Android/iOS) |
| **Veritabanı** | Supabase | Gerçek Zamanlı Veri ve Kimlik Doğrulama |
| **Stil / UI** | Tailwind & Radix | Tasarım Sistemi ve Erişilebilirlik |
| **Animasyon** | Framer Motion | Etkileşimli Kullanıcı Arayüzü |
